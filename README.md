## Introduction

這是一個專門針對日本競艇的下注機器，計劃上是由 @hochienH 先想下注策略，然後讓 Claude 去找資料、寫模型學習、開發與落地。

## Strategies

@hochienH 的下注策略如下：

### 穴狙い
核心的目標就是想找到穴，然後針對穴下注，原則上不允許（除非賠率很高）下注 1-2-3 BOX 這種組合，因為長久下來要給莊家抽成，這樣是負和的，我所擬定的策略是希望讓模型先學會什麼情況底下會出現穴，出現穴的時候再來下注，所以如果一整天都沒有穴，完全不下注的情況也是有可能會發生的

那麼什麼時候會發生穴，這會想要用 Machine Learning 跟 Rule Based 去做，Rule Based 的話想像上會有一些文章，比如說天氣（風、雨）的影響，選手的影響或是引擎的影響都有可能，理想上是把所有的假說都換成可以跑的代碼，實際在過去的 Data 當中跑跑看，看會不會（或有多高的機率）依循這樣的條件而出現穴。其次在這個 Rule Based 底下，我們會再進一步地使用機器學習提高命中穴的機率

這個任務的目標是希望 Precision 高而不是 Recall 高，因為 Recall 就算低代價也就是不下注而已，長遠來看還是賺的，但 Precision 非常重要，因為會直接影響到下注策略

### 下注策略

基本上下單的策略會限制在三連單、三連複跟二連單（BOX 可以視為是數個三連單的組合）

下注的根據應該會同樣透過機器學習跟 Rule Based 去學，比如說傳統上大家是怎麼看這些數據，然後再搭配機器學習去補足

這個任務的目標是讓機器分別去預測這三個不同的組合，然後如果買所有前面的組合，直到買到的中的位置為止，這樣去計算總共多少錢，來決定機器的表現
